## 📌 Présentation

Ce projet est le portfolio professionnel de **Rosita Diouf**, conçu pour mettre en valeur ses compétences et réalisations à la croisée du **design UI/UX**, de la **communication digitale**, de la **technologie** et de l'**intelligence artificielle**.

### ✨ Caractéristiques du design
- **Interface Premium & Chaleureuse** : Palette harmonieuse inspirée de tons terreux et élégants (Bordeaux `#7B1E2B`, Caramel `#A67C52`, Crème `#DCC7AD`).
- **Composition moderne** : Éléments 3D flottants, cartes en glassmorphism, ombres subtiles et profondeur visuelle.
- **Micro-interactions soignées** : Animations au défilement (*IntersectionObserver*), transitions fluides, accordéons interactifs.
- **100% Responsive** : Expérience optimisée sur mobile, tablette et grand écran.
- **Accessibilité & Performance** : Respect de `prefers-reduced-motion`, structure sémantique HTML5, typographie soignée (*Cormorant Garamond*, *Outfit*, *DM Mono*).

## 🛠️ Stack Technique

- **Framework & UI** : [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)

- **Styles** : [Tailwind CSS v4](https://tailwindcss.com/)

## 🚀 Installation et Démarrage Local

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- [npm](https://www.npmjs.com/) ou [pnpm](https://pnpm.io/)

### 1. Cloner le dépôt
```bash
git clone https://github.com/rositadiouf02-hub/Rosita-Diouf02.git
cd Rosita-Diouf02
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Lancer le serveur de développement
```bash
npm run dev
```
L'application sera accessible sur `http://localhost:8443` (ou le port indiqué par Vite).

### 4. Compiler pour la production
```bash
npm run build
```
Les fichiers générés se trouveront dans le dossier `dist/`.
